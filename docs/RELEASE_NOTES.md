# pre-smio 源码公开整理

本次仅公开源码、构建说明和许可证，不上传或替换安装包。

- 项目及源码中的应用名称、图标整理为 pre-smio，定位为 mio 的社区尝鲜版客户端。
- 包含多 VPS 节点、加密配置、浅色/深色主题和系统分身支持。
- 保留启动兼容处理、空连接崩溃修复和断开 VPN 修复。
- 源码构建版本为 1.0.3，沿用此前测试包的包名；覆盖升级需要使用相同的维护者签名密钥。

现有 Release `presmio` 的 `mio-1.0.2-arm64.apk` 由维护者自行上传，未因这次源码整理而更换。main 分支源码与该安装包的版本不同，请分别查看。

mio 使用 MoPL，本项目保留上游署名和许可；pre-smio 是社区客户端，不是 smio 官方发布。
